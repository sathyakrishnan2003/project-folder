\# CIA Career Intelligence — Portfolio Case Study



\## Problem

Candidates need a system to understand skills, identify gaps and prepare for career opportunities.



\## Solution

Built CIA Career Intelligence with 7 modules:

\- Skill Gap Analysis

\- Career Recommendation

\- Internship Matching

\- Learning Path

\- Resume Intelligence

\- Placement Readiness

\- Career Intelligence Report



\## Technology

Laravel, PHP, AI APIs and ChromaDB.



\## Outcome

The system provides structured career analysis, recommendations and learning guidance.
