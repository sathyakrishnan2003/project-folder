\# CIA Career Intelligence Architecture



\## 7 Modules



1\. Skill Gap Analysis

2\. Career Recommendation

3\. Internship Matching

4\. Learning Path

5\. Resume Intelligence

6\. Placement Readiness

7\. Career Intelligence Report



\## Data Flow



Candidate data → CIA API → AI/Matching Logic → Database/ChromaDB → JSON Response



\## Authentication



CIA endpoints require authenticated candidate access.



\## Storage



Candidate profiles, skills, scores and history are stored for career intelligence processing.
