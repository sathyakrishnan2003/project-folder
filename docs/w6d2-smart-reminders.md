\# W6D2 Smart Reminder Preferences



\## Features



\- Enable or disable Smart Reminders.

\- Select a preferred reminder time.

\- Configure the follow-up interval.

\- Display an AI-suggested follow-up time.

\- Save reminder preferences.



\## Reminder Flow



Lead

→ Reminder Preferences

→ Follow-up Interval

→ AI Suggested Timing

→ Reminder



\## Example Settings



\- Smart Reminders: Enabled

\- Reminder Time: 10:00

\- Follow-up Interval: 3 days
