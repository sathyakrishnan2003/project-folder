# W6D3 Performance Investigation

## Database Performance

Investigated activity-related queries for Calls, Meetings, and Tasks using MariaDB EXPLAIN.

## Issues Investigated

- Reviewed query execution plans.
- Checked database indexes.
- Investigated date-based activity queries.
- Reviewed possible indexing improvements.

## Debugging

The investigation focused on identifying inefficient table scans and determining whether existing indexes were being used.

## Known Issues

No confirmed production performance regression was identified in the local Docker environment.
